# 마음자로 iOS 문서–구현 격차 검토

2026-09-07. 사용자 요청: 위젯을 먼저 단순화하고, 계획서·PRD·기능명세와 현재 iOS 구현을 대조해 후속 작업 후보를 확인한다.

## 범위와 판정 기준

### 후속 승인 반영: 무료 30일 격자

아래 최초 검토 이후 사용자의 진행 승인에 따라 무료 최근 30일 격자를 구현했다. 월요일 시작의 요일 행과 주별 열로 배치하고, 기간 밖 날짜는 빈칸으로 두며 날짜 셀을 누르면 기존 상세 화면이 열린다. 횟수/강도 합 전환을 제공한다. Pro 52주와 고급 분석은 유지한다. 따라서 아래의 무료 격자 승인 대기 설명은 최초 검토 시점의 상태다. 최신 검증 결과는 `iOSApp/QA/FreeHistoryGrid.md`를 기준으로 한다.

- 기준 자료: `docs/maeumjaro_minimal_mind_control_app_prd_v3_2026-09-04.md`, `docs/마음자로_PRD.md`, `docs/maeumjaro_interactive_product_plan_v1.html`, `docs/마음자로_기능명세서.png`, `docs/maeumjaro_pen/`의 통합·상태·인터랙션 문서, `.omo/plans/maeumjaro-ios-implementation.md`.
- 구현 비교: `iOSApp/Maeumjaro/Features`, `iOSApp/Packages/MaeumjaroCore`, 위젯과 관련 테스트 소스. 코드 존재는 실행 검증 완료를 의미하지 않는다.
- 최신 사용자 결정인 비의료적 자기조절 앱, 텍스트 최소화, 기존 펜 형태 유지, 모든 강도에서 동일한 시작 액상량과 색상 구분을 우선한다. 이를 다시 승인받을 필요는 없다.
- 이번 구현 범위는 위젯이다. 아래 분석·기록 개선은 제안이며 무료/Pro 정책과 기록 화면 코드는 변경하지 않았다.

## 핵심: 기록표가 없는 것이 아니라 현재 무료 화면에서 숨겨져 있다

`HistoryView.swift:8`은 `policy.canAccess(.heatmap)`일 때만 `HeatmapGrid`를 표시하고, 무료 사용자에게는 `FreeDailyListView`를 표시한다. 상세 분석도 Pro 조건 아래 있다. 따라서 무료 사용자에게 “기록표·분석 기능이 없다”는 경험이 생긴다.

- PRD v3 §4와 §12는 기여도형 히트맵을 주요 기능으로 설명한다. 구 PRD §4.2 및 인터랙티브 시안은 최근 16주 격자를 보여준다.
- 한편 v3 §25 자체도 무료 최근 30일, Pro 52주 히트맵을 구분한다. 최신 iOS 계획은 이를 무료 30일 목록 / Pro 52주 히트맵으로 구체화했다.
- 그러므로 단순 누락으로 단정할 수 없다. **무료에도 짧은 기간의 격자를 제공할지**를 명시적으로 결정하는 작업이 필요하다.
- 권장: 무료 30일 격자 + Pro 52주 격자/고급 분석. 기존 무료 보관 범위를 넓히지 않고 핵심 경험을 보여줄 수 있다. 이는 승인 전 제안이다.

## 구현이 이미 있는 부분

- 일별 횟수/강도 합, 3시간 간격 분포, 요일/강도 분포, 활동일 평균, 기간 비교 집계.
- 무료 최근 30일, Pro 52주, 최근 16주 초기 표시를 위한 기간 모델.
- 기록 상세 열기 및 개별 기록 삭제 확인 흐름.
- 타임존·날짜 경계·표본 수 등 집계 단위 테스트 소스.

위 항목은 새로 처음부터 만들기보다 노출 정책, 화면 연결, 명세와 다른 표현, 실제 렌더 검증을 보완하는 편이 적절하다.

## 시안을 그대로 제품 요구로 옮기지 않을 항목

- 인터랙티브 HTML의 예시 데이터/브라우저 기록 토글은 데모 장치다. 최신 native 계획은 가짜 기록을 제품에 섞지 않는 방향이므로 자동 이식하지 않는다.
- 액상 색으로 강도를 구분하는 규칙과 기록표의 횟수/강도 합 색상 단계는 다른 의미다. 동일한 색상 규칙으로 무조건 합치지 않는다.
- 접근성과 실제 데이터 의미를 해치는 수준으로 기록 화면의 숫자·라벨까지 제거하지 않는다. 사용자는 로그 이외의 텍스트 최소화를 요청했다.

## 이번 위젯 변경

이번 위젯의 강도 조절 제거는 과거 계획의 누락이 아니라 최신 사용자 승인에 따른 단순화다. 과거 문서를 근거로 +/- 컨트롤을 다시 추가하지 않는다.

- 소형은 작은 원본 펜, 선택 강도를 나타내는 색 점, 오늘 기록이 있을 때 체크 표시로 단순화.
- 위젯 전체 탭은 기존 `maeumjaro://inject?source=widget`으로 연결. 위젯의 +/- 버튼 제거, 앱 설정의 강도 선택은 유지.
- 잠금화면 원형 진입점 추가. 단색 펜 심벌 사용.
- 기존 중형 배치가 지원 대상에서 사라지지 않도록 중형은 유지하되 같은 단일 진입점으로 단순화. 물리적 위젯 크기는 iOS 규격이며 기존 배치를 자동 축소하지 않음.
- 기존 AppIntent 및 저장 데이터는 제거하지 않음. 다른 시스템 진입점이나 기존 데이터 계약을 변경하지 않음.

검증 결과와 미완료 사항은 `iOSApp/QA/CompactWidget.md`에 기록한다.

## 추천 실행 순서

1. 위젯 실제 배치 후 전체 탭 진입과 완료 표시 갱신, 잠금화면 원형 진입 확인.
2. 무료 30일도 격자로 보여줄지 사용자 결정. 현행 최신 계획은 무료 목록/Pro 격자이므로 변경 시 정책 수정과 테스트를 함께 진행.
3. 기록 격자의 직접 날짜 선택·고정 색상 단계·범례, 날짜 상세의 완료 시각/평균을 구현.
4. 데이터 분석 화면의 정보 순서와 적은 기록/빈 상태를 다듬고 실제 데이터 fixture로 검증.
5. 내보내기·Pro 권한·접근성·실기기 검증 후 남은 선택 기능을 검토.
