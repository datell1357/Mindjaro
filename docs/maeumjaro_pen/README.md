# 마음자로 앱용 펜 에셋 패키지

마음자로의 잠금 해제와 마음 정리 의식에 사용하는 정면형 2.5D 펜 에셋이다. 실제 의약품, 제품명, 제약사 표기, 용량 또는 바늘 표현을 포함하지 않는다.

## 경로

- 런타임 에셋: `../../assets/maeumjaro_pen/`
- 기계 판독 계약: `integration_contract.json`
- 인터랙션·시각 명세: `interaction_design.md`
- 검증 결과와 적용 경계: `qa.md`

## 런타임 에셋

| 파일 | 크기 | 역할 |
| --- | ---: | --- |
| `maeumjaro_pen_2d_locked.png` | 1024×1536 | 정적 잠금 상태 또는 폴백 |
| `maeumjaro_pen_2d_ready.png` | 1024×1536 | 합성 애니메이션의 기본 본체 및 정적 해제 상태 |
| `maeumjaro_pen_2d_complete.png` | 1024×1536 | 정적 완료 상태 또는 폴백 |
| `maeumjaro_pen_2d_ring_locked.png` | 300×112 | 회전 링의 잠금 앞면 |
| `maeumjaro_pen_2d_ring_ready.png` | 300×112 | 회전 링의 해제 뒷면 |
| `maeumjaro_pen_2d_window_empty.png` | 126×414 | 액체 창의 고정 빈 배경 |
| `maeumjaro_pen_2d_liquid_full.png` | 126×414 | 연속 감소시키는 액체 레이어 |

모든 파일은 알파 채널이 있는 PNG다. 중간 진행률 이미지는 사용하지 않는다.

## 앱 합성 순서

1. `maeumjaro_pen_2d_ready.png`를 1024×1536 기준 아트보드로 표시한다.
2. 액체 영역 `(x: 449, y: 650, width: 126, height: 414)`에 빈 창과 액체 레이어를 차례로 겹친다.
3. 상단 링 영역 `(x: 362, y: 136, width: 300, height: 112)`에 잠금/해제 링 면을 앞뒤로 배치한다.
4. 잠금 해제 진행률을 링 Y축 회전 `0° → ±180°`에 연결한다.
5. 해제 상태에서 다시 밀면 동일 링을 `±180° → ±360°`로 회전해 잠근다.
6. 긴 누르기 진행률 `p`를 액체 상단 마스크 `p × 414px`에 연결한다. 남은 액체 높이는 `(1 - p) × 414px`다.
7. 손을 떼면 현재 `p`를 유지하고, 다시 누르면 그 값부터 이어간다. `p = 1`에서만 완료 기록과 햅틱을 한 번 실행한다.

터치 영역은 작은 링에 한정하지 않고 펜 전체를 최소 44pt 이상으로 제공한다. 정확한 임계값과 상태 전이는 `integration_contract.json`을 따른다.

## 개발 경계

- 이 패키지는 래스터 에셋과 인터랙션 계약이다. Android Compose 또는 iOS SwiftUI 소스에 아직 연결되지 않았다.
- 실제 기기 FPS, 메모리, 첫 프레임 로딩은 앱 통합 단계에서 별도로 측정해야 한다.
- 애니메이션이 필요 없는 화면에서는 `locked`, `ready`, `complete` 정적 이미지를 폴백으로 사용할 수 있다.
