# 마음자로 Android 스토어 문안 초안

상태: 내부 검토용 비공개 초안. `마음자로`는 가칭이며, 이 문서는 게시·심사·승인을 의미하지 않는다.

## 앱 이름

마음자로

## 짧은 설명

충동의 순간, 짧은 자기조절 의식과 나의 사용 패턴을 기록해 보세요.

## 전체 설명

먹고 싶은 순간, 홈 화면 위젯이나 앱에서 마음자로를 열어 보세요. 펜을 열고 화면을 잠시 길게 누르는 짧은 가상 의식으로 충동과 다음 행동 사이에 멈춤을 만듭니다.

선택한 마인드 강도와 사용 시각은 기기에 기록됩니다. 기록 화면에서 오늘의 실행 횟수, 누적 강도, 날짜별 히트맵과 시간대·요일 패턴을 확인할 수 있습니다.

- 마인드 강도 1~5 선택
- 홈 화면 위젯에서 바로 시작
- 화면 길게 누르기와 시각·촉각 피드백
- 완료한 실행만 로컬 기록
- CSV/JSON 내보내기와 전체 기록 삭제
- 햅틱, 사운드, 모션 감소 설정

마음자로의 강도와 가상 주입은 앱 안의 시각·촉각 표현입니다. 이 앱은 의료기기나 의약품이 아니며 실제 의약품이나 의료인의 진료를 대체하지 않습니다. 질병의 진단·치료·완치·예방 또는 식욕 억제 효과를 약속하지 않습니다.

## Pro 문안 초안

Pro는 장기 패턴 분석, 추가 기록 범위, JSON 내보내기와 꾸미기 기능을 여는 일회성 구매 항목으로 기획되어 있습니다. 제공 범위·가격·상품 ID는 Play Console 설정과 소유자 승인 후 확정합니다. 구매가 없어도 핵심 의식, 무료 기록, CSV 내보내기와 기록 삭제는 사용할 수 있어야 합니다.

## 금지 표현

다음 표현은 스토어 문안과 스크린샷에서 사용하지 않는다.

- 마운자로, 제약사 또는 다른 실제 의약품을 연상시키는 공식성 표현
- `mg`, 용량, 투여량, 처방, 복약, 약효, 지속 시간
- 치료, 예방, 완치, 식욕 억제, 체중 감량 효과의 단정
- 의료기기·의약품·전문가의 대체를 암시하는 표현
