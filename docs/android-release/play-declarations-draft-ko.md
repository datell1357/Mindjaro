# Google Play 선언 초안

상태: Play Console 제출 전 내부 평가. 아래 값은 권장 답변 초안이며 최종 선언이 아니다.

## Data Safety 평가

| 질문 | 내부 초안 | 근거와 남은 확인 |
|---|---|---|
| 데이터 수집 | 개발자 앱 수집은 아니오로 제안 | 앱 코드에서 개발자 운영 원격 API·분석·광고 SDK는 확인되지 않았다. 그러나 release 병합 매니페스트에는 전이 의존성이 추가한 `android.permission.INTERNET`이 있고, Play Billing/포함 Google SDK가 Google Play 또는 네트워크와 통신할 수 있다. Google Play가 처리할 수 있는 거래·구매·계정·기기 관련 정보의 최신 분류는 별도 확인 |
| 데이터 공유 | 개발자 서버 공유는 아니오로 제안 | 개발자 서버 전송 경로는 확인되지 않았다. 이 답변을 Google Play의 처리·공유가 없다는 뜻으로 확대하지 않으며, Billing 관련 Google Play 고지와 Console 문항을 별도 검토 |
| 앱 기능에 필요한 로컬 기록 | 예, 기기 내 처리 | 완료 시각·강도·진입 경로·문구 ID가 Room에 저장된다. Play 질문의 분류명은 Console 최신 문항에 맞춰 선택 |
| 암호화 전송 | 개발자 서버 전송은 해당 없음으로 제안 | Billing/포함 SDK의 Google Play 통신은 별도 네트워크 경로이므로 이 답변으로 제외하지 않는다. 최종 AAB의 SDK·매니페스트·실제 전송과 Console 최신 문항을 확인한 후 확정 |
| 삭제 요청 | 앱 내 삭제 제공 | 설정의 전체 기록 삭제와 앱 데이터 삭제를 확인하고 질문 문항에 맞게 답변 |
| 계정 생성 | 아니오 | 회원가입·로그인 기능 없음 |

Data Safety는 소스 코드만으로 확정할 수 없다. 출시 artifact, 병합 매니페스트, 포함 SDK, Billing 구성, 실제 전송 로그를 같은 checksum에 묶어 재검토한다. 특히 결제수단·구매자 식별 정보 등 구매 관련 정보의 처리 주체와 분류는 이 초안에서 단정하지 않고 Google Play의 최신 고지와 Console 문항으로 확인한다.

## Health Apps Declaration 평가

현재 PRD는 웰니스·자기조절 의식과 패턴 기록을 정의하며 의료기기·의약품·치료 기능을 제외합니다. 따라서 다음을 내부 검토 방향으로 제안합니다.

- 의료기기 또는 의약품 투여 앱으로 선언하지 않는다.
- 실제 건강 측정값, 진단·치료, 처방·복약, 체중·질병 데이터를 수집하거나 Health Connect와 연동하지 않는다고 답한다.
- 앱 설명에 비의료적 성격과 실제 의약품·의료인의 대체가 아님을 명시한다.
- Play Console이 제시하는 최신 범주 중 실제 기능에 맞는 웰니스/스트레스 관리 또는 영양·체중 관리 분류가 필요한지 소유자와 정책 검토로 결정한다.

최종 Health Apps Declaration은 콘솔 문항, 지역 정책, 최신 앱 기능을 직접 보고 소유자가 제출해야 한다.

## Content rating 평가 초안

응답 방향은 다음과 같습니다.

- 폭력: 없음
- 성적 콘텐츠: 없음
- 도박: 없음
- 약물·주류·담배 홍보: 없음
- 사용자 생성 콘텐츠: 없음(MVP)
- 건강·의료 효능 주장: 없음; 비의료적 면책문구를 사용

실제 질문 문항과 대상 연령 등급은 Play의 현재 설문 결과가 결정하므로 이 초안을 등급 자체로 사용하지 않는다.
