# 마음자로 개인정보처리방침 초안

상태: 공개 URL 게시 전 내부 검토용 초안. 법률 검토와 운영 주체·문의처 확정이 필요하다.

시행일: `[소유자 확정 필요]`

## 1. 처리 목적

마음자로는 사용자가 시작한 자기조절 의식의 완료 기록과 앱 설정을 제공하기 위해 데이터를 처리합니다.

## 2. 처리하는 정보

현재 Android 소스와 제품 PRD에서 확인되는 로컬 기록 항목은 다음과 같습니다.

- 이벤트 ID·의식 시작/완료 시각·기록 생성 시각
- 완료 시점의 로컬 날짜·시간대 오프셋
- 마인드 강도 1~5
- 진입 경로(위젯 또는 앱)
- 표시 문구 ID
- 완료 여부 및 앱 내부 상태
- 애니메이션 지속시간·중단 횟수·앱 버전
- 사용자가 선택한 기본 강도·햅틱·사운드·모션 감소 설정
- 문구 톤·테마·위젯별 강도와 온보딩 완료 상태
- Pro 사용자가 작성한 문구 본문·톤·카테고리·작성/수정 시각·로컬 검증 결과·보관 상태
- Pro 권한 확인 상태·상품 ID·마지막 확인 시각의 로컬 캐시

이름, 이메일, 전화번호, 정확한 위치, 연락처, 카메라, 사진, 마이크, 광고 식별자, 체중·질병·처방약 정보의 전용 입력 항목이나 자동 수집 기능은 제공하지 않습니다. 다만 사용자가 자유 입력 문구에 포함한 정보는 문구 본문과 함께 로컬에 저장될 수 있습니다.

## 3. 저장 위치와 전송

제품 설계는 기록과 설정을 기기에 로컬 저장하고 개발자 서버로 전송하지 않는 방식입니다. 앱 코드에서 개발자가 운영하는 원격 API·분석 SDK·광고 SDK 사용은 확인되지 않았습니다. 다만 release 병합 매니페스트에는 앱이 직접 선언하지 않은 `android.permission.INTERNET`이 포함되어 있으며, 이는 포함된 Google Play Billing SDK 등 전이 의존성이 추가한 권한일 수 있습니다. 따라서 앱에 직접 네트워크 API나 개발자 서버가 없다는 사실을 `INTERNET` 권한이 없다는 뜻으로 해석하지 않습니다.

Google Play Billing은 상품 조회·구매·구매 복원을 위해 Google Play 및 네트워크와 통신할 수 있습니다. 이 과정에서 거래·구매·계정 또는 기기 관련 정보가 Google Play의 정책에 따라 처리될 수 있으므로, 이 초안은 Google Play가 처리하는 정보의 세부 범주나 보관 기간을 단정하지 않습니다. 최종 개인정보처리방침은 실제 release AAB의 병합 매니페스트·포함 SDK·네트워크 동작과 Google Play의 최신 고지를 대조해 확정해야 합니다.

## 4. 내보내기

CSV/JSON 파일은 사용자가 명시적으로 내보내기를 선택할 때 앱 캐시에 만들고 Android Sharesheet를 통해 공유합니다. 앱은 자동 업로드를 수행하지 않습니다. 공유 대상과 보관 방식은 사용자가 선택한 앱의 정책을 따릅니다.

## 5. 삭제와 보관

사용자는 설정에서 모든 의식 완료 기록을 삭제할 수 있습니다. 이 동작은 사용자 문구·앱 설정·Pro 권한 캐시 또는 이미 내보낸 파일까지 삭제하는 기능이 아닙니다. 사용자 문구의 ‘보관’은 선택 목록에서 제외하는 동작이며, 기존 기록의 문구를 표시하기 위해 원문을 로컬에 유지합니다. 앱 삭제 시 운영체제가 앱 데이터를 제거하는 범위가 적용됩니다. 캐시로 생성된 내보내기 파일은 앱의 캐시 정책에 따릅니다. 백업 및 기기 간 전송에서는 Room·DataStore 기록을 제외하도록 구성되어 있으나, 최종 artifact에서 다시 확인해야 합니다.

## 6. 아동 및 민감정보

앱은 의료 진단·치료를 제공하지 않으며 건강정보 전용 입력 항목이 없습니다. 다만 Pro의 자유 입력 문구는 사용자가 작성하므로 민감정보가 입력되지 않는다고 보장할 수 없습니다. 문구는 기기 내에서 검증하며 검출된 의료·효능 표현이 있는 문구를 새 의식의 선택 후보에서 제외합니다. 이 검증은 모든 민감정보를 탐지하거나 기존 저장 원문을 삭제하는 기능이 아닙니다. 대상 연령과 아동 관련 처리는 Play Console의 콘텐츠 등급·정책 질문에 답하기 전에 소유자와 법률 검토로 확정합니다.

## 7. 문의처와 권리

운영자명, 사업자 정보, 문의 이메일, 관할 법률, 열람·정정·삭제 요청 절차는 `[소유자 확정 필요]`입니다. 이 항목이 확정되고 공개 URL에서 접근 가능해질 때까지 개인정보처리방침 게이트는 미완료입니다.
