01 / 즉시성

충동 순간에 바로

03 / 짧은 완결성

3~6초 안에 끝

타이머나 사후 확인 없이 주입 애니메이션과 마인드 컨트롤 문구를 본 뒤 핵심 경험이 끝납니다.

04 / 사실 기반

측정한 것만 표시

실제 식욕 감소나 참기 성공을 추정하지 않고, 완료 시각·강도·사용 빈도만 시각화합니다.

  • 누르는 동안만 진행

HOLD INTERACTION

액체 감소와 촉각 피드백을 같은 진행률에 묶습니다.

강도가 높을수록 초기 액체량과 진행 시간이 늘고, 햅틱 펄스가 촘촘해집니다. 손을 떼면 멈추고 다시 누르면 이어집니다.

  • 강도별 1.2~2.6초 목표
  • 액체·플런저·진행 바 동기화
  • 중단 시 기록 생성 안 함
COMPLETION

강도와 한 문장만 남깁니다.

완료 시 ‘강도 N 주입 완료’, 가상 주입량, 자동 기록 시각과 마인드 컨트롤 문구를 표시합니다. 성공 여부는 묻지 않습니다.

  • 최근 10개 문구 중복 방지

  • 실제 생리적 효과를 단정하지 않음

SELECT
  local_date,
  COUNT(*) AS injection_count,
  SUM(intensity) AS intensity_sum,
  AVG(intensity) AS intensity_avg
FROM injection_events
WHERE completed_at IS NOT NULL
GROUP BY local_date;
