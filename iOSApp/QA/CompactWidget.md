# 소형 중심 위젯 검증

2026-09-07. 위젯을 먼저 단순화하라는 사용자 요청에 따른 변경.

## 변경

- 소형: 작은 원본 펜 + 강도 색 점 + 오늘 기록이 있으면 체크. 텍스트와 +/- 컨트롤 제거.
- 전체 영역에 기존 펜 화면 deep link 적용. 강도와 횟수는 접근성 값에 유지하고 안내에서 없어진 버튼 설명 제거.
- 잠금화면용 accessoryCircular 지원 및 단색 펜 심벌 추가.
- 기존 중형 배치는 같은 간결한 내용으로 유지. 소형보다 작은 홈 화면 크기를 임의로 만들거나 기존 배치를 자동 축소하지 않음.
- 앱 설정의 강도 조절, 기존 AppIntent, 저장 데이터 유지.

## 실행 결과

- 전용 Maeumjaro QA iPhone 17 Pro (36828072-9948-42A2-8681-B311CC728CB8) 빌드 성공.
- 최종 위젯 테스트 10건 통과: `test_sim_2026-09-07T00-02-31-337Z_pid35947_ba95f12d.xcresult`.
- 렌더 행렬은 small/medium/circular × light/dark × 3 themes × strength1/5 × zero/nonzero 총 72개. 이미지 크기와 생성 확인이지 모든 조합에 대한 수동 시각 승인 또는 실제 WidgetKit 호스트 검증은 아니다.
- 같은 실행의 UI 검사 1건 실패: `testBothWidgetSizesColdLaunchAndCancelWithoutAddingRecords`, `Required installed widget size missing`. 실제 설치된 필요한 크기의 위젯을 찾지 못했다. 딥링크 성공이나 실패 자체를 입증하지 않는다.
- 실패 후 남은 90초 cold-launch QA 인계 상태가 만료되어 일반 실행에서 테스트 인계 오류가 표시됐다. 동일 fixture를 명시적으로 다시 열어 기존 QA 초기화 경로로 해제한 뒤 인수 없는 일반 실행을 재확인했다. 최종 홈 화면 정상 표시, 사용자 기록 파일은 삭제하지 않았다.
- 테스트용 widgetFamily 환경값은 읽기 전용이어서 직접 주입 시 컴파일 실패했다. 이 주입을 제거하고 구성 요소별 렌더를 검증했다. 원형 위젯의 시스템 배경·틴트·잠금화면 배치는 별도 검증 필요.

## 남은 게이트

### 2026-09-07 위젯 이미지 크기 수정 및 재검증

- 위젯에 전달하는 UIImage를 `preparingThumbnail`로 192×288 픽셀로 축소하고 정적 캐시로 재사용한다. 64×96pt의 3배 해상도를 유지한다. 앱과 위젯 번들의 원본 PNG는 변경하지 않았다.
- 위젯 원본 1024×1536 유지와 실제 썸네일 192×288 검사를 추가했다. 위젯 테스트 11건 통과 (`test_sim_2026-09-07T00-52-19-218Z_pid35947_b4364d35.xcresult`).
- 실제 홈 화면 소형 위젯에서 회색 직사각형 대신 원본 펜 형태가 표시됨을 확인했다.
- 독립된 warm fixture로 소형 위젯 중앙 탭 → 잠금 해제 → 강도 5 완료 → 오늘 1회 → 위젯 접근성 값 오늘 1회 및 체크 표시 갱신 UI 테스트 통과 (`test_sim_2026-09-07T00-56-51-057Z_pid35947_34f40c79.xcresult`). 사용자 기록 삭제 없이 테스트 데이터만 1건 생성했다.
- 전후 캡처는 `.omo/evidence/widget-thumbnail-final/8222C569-6C42-4955-8FBE-2F1BDD738983.png`, `ED77D69F-059D-4A06-BE7A-0484A9EDCE81.png`에 보관했다. 체크 없는 색 점에서 체크 있는 색 점으로 갱신된 것을 시각 확인했다.
- 초기 UI 테스트의 하단 좌표, cold 전용 fixture ID 확인, 강도 5보다 짧은 유지 시간 오류를 고쳤다. 최종 테스트는 중앙 좌표, warm 실행 상태, 3.6초 유지를 사용한다. 이전 실패를 앱 완료 기능 결함으로 해석하지 않는다.
- 읽기 전용 코드 검토에서 추가 수정 의견 없음. 테스트 종료 후 일반 앱 실행으로 복귀했다.
- 아래 이전 이미지 크기 실패는 수정 전 기록이다. 중형 실제 배치, 가장자리 탭, 잠금화면 원형, 실제 자정 전환은 여전히 별도 검증 대상이다.
