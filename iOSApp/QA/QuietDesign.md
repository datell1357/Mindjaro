## 2026-09-07 화면 높이 중심 펜 확대

- 홈과 실행 화면에서 고정 너비·400pt 높이 제한을 없애고 사용 가능한 높이에 맞춰 펜을 확대했다. 원본의 좌우 투명 여백만 제외하며 펜의 종횡비와 원본 에셋은 유지한다.
- 설정·닫기 버튼, 하단 탭과 진행 표시 공간을 남겼다. 실행 중 상태 변화로 펜 위치가 바뀌지 않는 구조를 유지했다.
- 전용 iPhone 17 Pro 시뮬레이터 빌드·실행 성공. 확대 레이아웃 및 완료 후 기록 1회 UI 테스트 2건 통과 (`test_sim_2026-09-06T22-30-12-579Z_pid35947_d589f015.xcresult`). 레이아웃 검사는 실행 캔버스 높이 60% 초과, 닫기 버튼 비중첩, 잠금 해제 전후 프레임 안정성을 확인한다.
- 작은 기기·가로 방향·실기기는 이번 검증에 포함하지 않았다.

## 2026-09-07 펜 입력 및 표현 수정

### 사용자 피드백 후 원형 복원 및 맑은 액체색

- 새로 그렸던 캡슐형 링과 잠금 아이콘은 원본 PenRingLocked/PenRingReady PNG로 복원했다.
- 회전 중에는 원본의 세로 조각을 원통 각도에 따라 다시 배치한다. 전체 이미지의 평면 회전이나 반투명 교차 전환은 사용하지 않는다. 원본 가장자리의 투명 영역은 이웃 재질로 연장하고 원본 외곽 마스크로 잘라낸다.
- 잠금·해제 완료 각도에서는 원본 이미지를 직접 표시한다. 두 완료 상태의 렌더링 PNG가 원본 렌더링과 일치하는 테스트를 통과했다.
- 액체는 민트·아쿠아·하늘색·라일락·피치핑크로 변경했다. 명암 텍스처 밝기를 올려 기존 어두운 곱셈 색조를 보완했다. 동일한 시작 잔량과 수면 움직임은 유지한다.
- 링·액체 선택 테스트 15건 통과. 색상 비교 렌더는 `.omo/evidence/original-ring-clear-liquid/`에 보관했다.
- 수평 임계값·세로 이동 거부·재잠금 UI 검사와 완료 후 기록 1회 UI 검사, 원본 끝 상태 렌더 검사 총 3건 통과 (`test_sim_2026-09-06T15-40-43-983Z_pid58526_ff493e49.xcresult`).
- 마지막으로 아이콘이 없는 가장자리 재질만 부드럽게 연결했다. 원본 끝 상태 렌더 검사 1건 재통과 (`test_sim_2026-09-06T15-45-41-572Z_pid58526_f8865389.xcresult`), 중간 각도 캡처는 `.omo/evidence/original-ring-smooth-seam/`에 보관했다. 이후 시뮬레이터 빌드·실행 성공. 마지막 재질 연결 변경 후 UI 검사는 재실행하지 않았다.
- 이 방식은 기존 2D 원본을 이용한 원통 표면 근사이며, 새 3D 모델 제작은 아니다.
- 최종 재질 연결 코드로 링·액체 테스트 15건 재통과 (`test_sim_2026-09-06T15-47-22-023Z_pid58526_c56bac68.xcresult`). 재질 연결 코드의 독립 읽기 전용 검토에서 심각한 결함은 발견되지 않았다. 전체 앱 회귀·실기기·연속 회전 영상 검증을 뜻하지 않는다.

### 이전 수정 이력 (링 표현과 색상은 위 수정으로 대체)

- 입력 로그에서 잠금 해제 첫 이동이 `dx 6.67, dy -9.67`로 기록됐다. 잠금 안내 화살표 제거로 캔버스가 이동해 세로 이동 취소 조건을 충족했다. 화살표를 동일한 뷰로 유지하고 불투명도만 바꿔 위치 변화를 없앴다.
- SwiftUI DragGesture와 기존 취소 처리를 유지했다. 실험한 UIKit 터치 표면 및 임시 입력 로그는 최종 코드에 남기지 않았다.
- 모든 강도의 시작 채움 비율을 1로 통일했다. 색은 1 세이지, 2 청록, 3 파랑, 4 라벤더, 5 로즈다. 기존 시간·햅틱 설정은 유지했다.
- 액체 텍스처의 명암을 보존한 채 색을 입히고 수면 보간과 60Hz 타임라인을 적용했다. Reduce Motion에서는 장식 움직임을 제한한다.
- 링은 평면 PNG 전체의 3D 회전 대신 고정 실루엣과 조명, 원통 표면을 따르는 잠금 표시로 그린다. 완전한 3D 모델이나 three.js 도입은 아니다.
- 도메인 테스트 53건 통과. 최종 브랜드·액체·링 선택 테스트 21건 통과.
- 잠금 해제 → 누르기 → 완료 → 기록 1회 UI 테스트 통과. 결과 `test_sim_2026-09-06T15-18-28-322Z_pid58526_7726f2d2.xcresult`. 실제 화면 증거는 `.omo/evidence/pen-fixed-success/`.
- 손 떼기·재개 후 1회 기록 UI 검사 통과. 수평 임계값·세로 이동 거부·양방향 잠금 및 해제·기록 0회 검사도 통과했다. 마지막 결과 `test_sim_2026-09-06T15-21-56-851Z_pid58526_5953c43b.xcresult`.
- 아래 9월 6일 실패 기록은 수정 전 이력이다. 전체 앱 회귀 검사 및 실기기 검증 완료를 뜻하지 않는다.

## 미완료 사항

- 펜 밀기 → 누르기 → 완료 → 기록 1회 UI 테스트 실패. 밀기 직후 접근성 트리에 PenRingLocked가 남아 있다. 완료 저장 자체의 오류로 단정할 수 없다.
- 좌표 변경과 스크롤 구조 변경으로 해소되지 않았다. 제스처 전달 또는 취소 순서를 별도 계측해야 한다.
- 닫기 테스트 통과는 잠금 해제 성공을 입증하지 않는다.
- 기존 UI 테스트의 탐색 경로와 선택자를 수정했으나 전체 회귀 테스트는 실행하지 않았다.
- 완료 화면의 작은 화면·접근성 글꼴 렌더링 및 홈 화면에 배치한 실제 위젯 상호작용은 최종 확인 전이다.
