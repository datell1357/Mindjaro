# 온보딩 중앙 배치·완료 문구·설정 막대그래프

2026-09-12. iOS 앱 변경 및 iPhone 17 Pro / iOS 26.5 시뮬레이터 검증.

## 변경

- 온보딩 제목·설명·선택 내용을 진행 표시와 하단 버튼 사이에 세로 중앙 배치한다. 큰 글씨에서는 내용 영역을 스크롤할 수 있고 하단 진행 버튼은 유지한다.
- 저장 성공 후 기존 문구 선택기가 고른 `phraseText`를 완료 화면 중앙에 표시한다. 문구 톤 설정과 저장된 phrase ID 계약을 재사용한다. 완료 화면을 별도로 배치해 펜 아래로 스크롤하지 않아도 문구와 기록 보기·다시 실행을 볼 수 있다.
- 설정 상단에 오늘을 포함한 최근 7일 완료 횟수 막대그래프와 합계를 표시한다. 기존 기록 집계의 저장 당시 현지 날짜를 사용하며 기록 없는 날은 0회로 포함한다. 로딩·실패·재시도·빈 상태와 날짜별 접근성 값을 제공한다.

## 검증

- Debug 빌드·설치·일반 실행 성공.
- 최초 선택 실행: 17건 중 16 PASS, 1 FAIL, skip 0. 실패는 새 UI 테스트가 기록 탭에서 홈 전용 설정 버튼을 찾은 경로 오류였다. 제품 코드 수정 없이 홈 탭 이동을 추가했다.
- 해당 테스트 재실행: 1 PASS / 0 FAIL / 0 skip. 최종적으로 선택한 17개 테스트 모두 통과했으며 전체 앱 테스트 실행을 의미하지 않는다.
- 단위/호스트 11건: 기록 정책·주 정렬·연도 경계의 7일 집계·빈 날짜·이전 기록 제외, 문구 선택, 중단·재개 및 중복 저장 방지 등.
